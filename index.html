Instalacja Debiana 12

Kompletny przewodnik instalacji systemu Debian 12 "Bookworm" — od pobrania ISO aż do pierwszego uruchomienia. Każdy krok opisany dokładnie, z komendami gotowymi do skopiowania.

01
Pobierz obraz ISO DOWNLOAD

Wejdź na oficjalną stronę Debiana i pobierz najnowszy obraz instalacyjny. Zalecamy wersję netinst (~650MB) — pobiera resztę pakietów przez internet podczas instalacji.

ℹ️Masz słaby internet? Pobierz pełne DVD (~4GB) — zawiera wszystko offline.
# Pobierz przez wget (terminal Linux/Mac):
wget https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-12.5.0-amd64-netinst.iso

# Sprawdź sumę kontrolną SHA512:
sha512sum debian-12.5.0-amd64-netinst.iso
02
Nagraj ISO na pendrive USB BOOT

Użyj programu Rufus (Windows) lub Balena Etcher (Linux/Mac/Win) do nagrania obrazu na pendrive minimum 2GB. Na Linuxie możesz też użyć komendy dd.

⚠️Pendrive zostanie CAŁKOWICIE wymazany! Zrób backup danych przed nagraniem.
# Linux — nagraj przez dd (zamień /dev/sdX na swój pendrive):
sudo dd if=debian-12.5.0-amd64-netinst.iso of=/dev/sdX bs=4M status=progress
sudo sync

# Sprawdź numer pendrive przed użyciem dd!
lsblk
03
Uruchom z USB w BIOS/UEFI BIOS

Włóż pendrive, uruchom ponownie komputer i wejdź do BIOS/UEFI. Ustaw pendrive jako pierwsze urządzenie bootujące lub użyj Boot Menu (jednorazowy wybór).

# Klawisze wejścia do BIOS / Boot Menu:
ASUS     → F2 lub DEL   (BIOS)  │  F8   (Boot Menu)
GIGABYTE → DEL         (BIOS)  │  F12  (Boot Menu)
MSI      → DEL         (BIOS)  │  F11  (Boot Menu)
Lenovo   → F1 lub F2   (BIOS)  │  F12  (Boot Menu)
HP       → F10         (BIOS)  │  F9   (Boot Menu)
Dell     → F2          (BIOS)  │  F12  (Boot Menu)
ℹ️UEFI Secure Boot — możesz go wyłączyć lub zostawić, Debian 12 obsługuje Secure Boot natywnie.
04
Wybierz tryb instalacji INSTALLER

Po uruchomieniu z pendrive pojawi się menu bootloadera. Masz dwie opcje: Graphical Install (graficzna, łatwiejsza) lub Install (tekstowa, szybsza).

┌─────────────────────────────────────────┐
│       Debian GNU/Linux Installer        │
├─────────────────────────────────────────┤
  ► Graphical install               ← WYBIERZ TO
    Install
    Advanced options ...
    Accessible dark contrast installer ...
└─────────────────────────────────────────┘
05
Język, strefa czasowa, klawiatura SETUP

Przejdź przez kolejne ekrany instalatora. Instalator jest intuicyjny — kliknij dalej po wyborze każdej opcji.

Język:             Polish (Polski)
Kraj/Region:       Poland
Układ klawiatury:  Polish
Hostname:          debian        ← możesz zmienić na co chcesz
Domain:            local         ← lub zostaw puste
06
Hasła i użytkownicy USERS

Ustaw hasło root i utwórz konto użytkownika. Root to administrator systemu — nie używaj go na co dzień, tylko do zarządzania systemem.

⚠️Hasło root musi być silne — min. 12 znaków, wielkie litery, cyfry, znaki specjalne. Możesz też zostawić root puste — wtedy sudo jest dostępne automatycznie dla użytkownika.
Root password:     ••••••••••••     ← silne hasło admina
Full name:         Mikołaj
Username:          mikolaj          ← małe litery, bez spacji
User password:     ••••••••••••
07
Partycjonowanie dysku DISK

Najważniejszy krok. Dla początkujących: Guided — use entire disk. Dla zaawansowanych: ręczne partycjonowanie z LVM lub szyfrowaniem.

⚠️UWAGA: partycjonowanie USUWA DANE z dysku! Zrób backup przed instalacją.
# Opcje partycjonowania (wybierz jedną):
  ► Guided - use entire disk           ← dla początkujących ✓
    Guided - use entire disk and LVM     ← zaawansowani
    Guided - entire disk with encryption ← z szyfrowaniem
    Manual                               ← pełna kontrola

# Zalecany schemat partycji (desktop):
/boot/efi   512 MB   FAT32   ← tylko dla UEFI
/           30 GB    ext4    ← system
swap        4 GB     swap    ← pamięć wymiany
/home       reszta   ext4    ← dane użytkownika
08
Wybór oprogramowania PACKAGES

Instalator zapyta co chcesz zainstalować. Odznacz zbędne desktopy, wybierz środowisko graficzne. Na serwerze — odznacz wszystko z wyjątkiem SSH i standard utilities.

# Zaznacz czego potrzebujesz (spacja = zaznacz):
  [✓] Debian desktop environment
  [✓] GNOME                       ← lub KDE/XFCE/inne
  [ ] ... Xfce
  [ ] ... KDE Plasma
  [✓] standard system utilities
  [✓] SSH server                  ← WAŻNE: dodaj SSH!
  [ ] web server                  ← niepotrzebne na desktopie
  [ ] print server                ← jeśli nie drukujesz
ℹ️Na serwerze bez GUI: odznacz wszystkie desktopy, zostaw tylko "standard system utilities" + "SSH server".
09
Instalacja bootloadera GRUB GRUB

Na końcu instalator zainstaluje bootloader GRUB. Zaakceptuj domyślną opcję instalacji na głównym dysku. Bez GRUB system się nie uruchomi!

# Instalator zapyta:
"Install the GRUB boot loader to your primary drive?"
  ► Yes                  ← kliknij YES !

# Wybierz dysk (zwykle pierwszy):
  ► /dev/sda             ← HDD / SATA SSD
    /dev/nvme0n1          ← NVMe SSD (M.2)
    /dev/vda              ← maszyna wirtualna
10
Pierwsze uruchomienie i aktualizacja DONE ✓

System gotowy! Wyjmij pendrive, uruchom ponownie. Po zalogowaniu wykonaj pierwszą aktualizację i zainstaluj przydatne pakiety. Debian działa!

# Zaloguj się jako root i zaktualizuj system:
su -
apt update && apt upgrade -y

# Zainstaluj przydatne narzędzia:
apt install -y sudo curl wget git neofetch htop nano vim

# Dodaj swojego użytkownika do grupy sudo:
usermod -aG sudo mikolaj

# Sprawdź wersję systemu:
cat /etc/debian_version

# Pokaż info o systemie (neofetch):
neofetch
✅Gotowe! Debian 12 "Bookworm" zainstalowany i skonfigurowany. Możesz teraz instalować pakiety przez apt install i korzystać z systemu.
mikolaj@debian:~$neofetch
